# 🌿 GreenLink - ESG Risk Assessment Platform Demo

This is a Streamlit-based ESG (Environmental, Social, Governance) risk assessment demonstration system, focusing on supply chain transparency and sustainability analysis.

## 🎯 Project Highlights

### Three Core Innovations

1. **Alternative Data + AI Analysis**
   - 🛰️ Sentinel-2 Satellite Remote Sensing Data
   - 📰 Public Sentiment Data Mining
   - 🤖 Python Automated Analysis

2. **E/S Separated Scoring**
   - Environmental (E): Verified based on satellite remote sensing
   - Social (S): Based on sentiment analysis
   - Precisely locate the source of risks

3. **B2B2C Value Loop**
   - B-end: Risk early warning and compliance reports
   - C-end: Consumer trust labels
